# Rock Paper Scissors — C++

A beginner-friendly console-based Rock Paper Scissors game written in C++.

## About

This project was created while learning the fundamentals of C++ programming.

The game allows the user to play Rock Paper Scissors against the computer. The computer randomly selects one of the three choices, and the program determines the result of each round.

## Features

- Rock, Paper, and Scissors choices
- Random computer choice
- Win, lose, and draw outcomes
- Score tracking
- Option to play multiple rounds
- Exit option
- Invalid input handling

## Concepts Practiced

- `if` / `else` statements
- `switch` statements
- `do...while` loops
- User input and output
- Random number generation
- Variables and basic data types
- Basic score tracking

## How to Run

1. Clone or download this repository.
2. Open `rock_paper_scissors.cpp` in a C++ compiler or IDE.
3. Compile and run the program.
4. Follow the instructions displayed in the console.
